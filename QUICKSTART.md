# Nimbus — 5-Minute Quickstart

## For the Impatient

You want a personal assistant app that works offline and never breaks. Here it is. No login page — you open it and it's just there.

### What You Get

- One chat page where you talk to an AI that understands tasks
- Four satellite pages: Tasks, Notes, Schedule, Clock
- Free Gemini AI (or offline if you skip the key)
- Free PostgreSQL (Neon) and hosting (Vercel)
- **Everything you see is stored. Nothing syncs to Google or anyone else.**

### What It Costs

**$0** (unless you exceed free tier limits, which take months).

- Vercel: free (100 serverless invocations/day)
- Neon: free (3 GB storage)
- Gemini: free tier

### Deploy in 10 Minutes

1. **Make an account**: Neon, Vercel, GitHub (if you don't have them)
2. **Clone this repo** to your machine:
   ```bash
   git clone <this-repo> && cd nimbus-assistant
   ```
3. **Create a database** at [neon.tech](https://neon.tech):
   - Click "New Project"
   - Copy the **pooled** connection string
4. **Get an API key** (optional but recommended):
   - Go to [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
   - Click "Create API Key"
   - Copy it
5. **Push to GitHub** (make the repo private — see note below):
   ```bash
   git remote set-url origin <your-github-repo>
   git push -u origin main
   ```
6. **Deploy on Vercel**:
   - Go to [vercel.com](https://vercel.com)
   - Click "Import Project"
   - Paste your GitHub repo URL
   - Add environment variables:
     - `DATABASE_URL` = your Neon pooled connection string
     - `GEMINI_API_KEY` = your API key from step 4
   - Click "Deploy"
7. **Run the migration** to set up the database:
   ```bash
   # From your local machine:
   npm install
   DATABASE_URL="<your-neon-connection-string>" npm run migrate
   ```
8. **Open your app**:
   - Click the Vercel deployment link — it opens straight into the chat, no sign-up
   - Start typing: `add task buy groceries tomorrow 6pm`

Done. You have a personal assistant.

### A Note on Privacy

There's no login page, which means anyone with your app's URL can use it and see your data. Keep the URL to yourself, or turn on Vercel's built-in Deployment Protection (a password prompt) in your project settings. Details in DEPLOYMENT.md.

### How to Use It

**In the chat:**
- `add task X by [time]` — creates a task
- `note: X` — creates a note
- `schedule X [time]` — adds an event
- `image of X` — generates an image
- `what are my tasks` — lists tasks
- `done X` — marks a task complete
- General questions → AI answers (if you added a key)

**In Tasks:**
- Click the checkbox to toggle done/not done
- Edit due date and priority inline
- Delete with the X button

**In Notes:**
- Click a note to edit it
- Pin notes with the star
- Search with the box at the top

**In Schedule:**
- Add events inline
- See a live 24-hour "day rail" showing today
- Events are displayed in your local time

**In Clock:**
- See the current time in multiple zones
- Set a timer with presets (5, 10, 25, 45 min)
- Change your timezone (everything re-displays immediately)

### Offline Mode

If you didn't add a `GEMINI_API_KEY`, the app still works:
- All capture commands (tasks, notes, events, images) work
- Open conversation says "add a key for open chat"

If you hit Gemini's rate limit, the app:
- Falls back to the offline brain
- Still captures your tasks
- Shows a note saying "AI unreachable — offline mode"

### What Happens With My Data?

**Everything is stored in your Neon database. Nothing leaves it.**

- Your tasks, notes, and schedule are in your database, not shared
- Gemini only sees the current chat message, not your stored data as a copy
- Images are generated by Pollinations, but the prompt is not stored on their side

You own your data. You can export it, delete it, or migrate it anytime.

### Customization

The styling and colors are defined in `app/globals.css`.
The AI system prompt is in `lib/ai.js`.
The offline brain (regex-based command parsing) is in `lib/localbrain.js`.

### Troubleshooting

**"DATABASE_URL is not set"**
→ Ensure the env var was added in Vercel settings before deployment. Go to the project, Settings, Environment Variables, add it, then redeploy.

**"Connection refused" when opening the app**
→ The app can't reach the database. Check that `DATABASE_URL` uses the **pooled** connection string and includes `sslmode=require`.

**Tasks are created in chat but don't show in the Tasks page**
→ Refresh the page. The data is there; it's just not loaded yet.

**Images don't load**
→ Pollinations generates them on demand. Wait a few seconds and refresh.
